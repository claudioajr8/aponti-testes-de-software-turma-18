# Atividade Avaliativa – Testes de Usabilidade

## 1. Cite 5 pontos que você exploraria livremente no sistema

1. **Navegação entre as telas:** verificar se os menus, botões e links são fáceis de encontrar e se levam o usuário para a tela correta.

2. **Cadastro e login:** testar se é simples criar uma conta, preencher os dados e acessar o sistema.

3. **Pesquisa e filtros:** verificar se a ferramenta de busca encontra as informações corretamente e se os filtros ajudam o usuário a localizar o que precisa.

4. **Preenchimento de formulários:** analisar se os campos são claros, se existem instruções e se o sistema informa quando algum dado foi preenchido incorretamente.

5. **Mensagens e notificações:** verificar se as mensagens de sucesso, erro ou confirmação são claras e ajudam o usuário a entender o que aconteceu.

## 2. Cite 5 possíveis problemas de usabilidade que poderiam existir

1. **Menus confusos ou mal organizados:** as funcionalidades podem estar em locais difíceis de encontrar.

2. **Botões sem identificação clara:** o usuário pode não entender qual ação será realizada ao clicar em determinado botão.

3. **Excesso de informações na tela:** muitas opções, textos ou elementos podem deixar a interface poluída e dificultar a visualização.

4. **Mensagens de erro pouco explicativas:** o sistema pode apresentar apenas mensagens genéricas, sem informar o motivo do erro ou como resolvê-lo.

5. **Sistema com baixa adaptação para celulares:** algumas telas podem ficar desorganizadas ou difíceis de utilizar em dispositivos móveis.

## 3. Explique por que esses problemas impactam o usuário

Os problemas de usabilidade podem causar dificuldade para navegar e utilizar as funcionalidades do sistema. Menus confusos e botões sem identificação podem fazer com que o usuário demore mais para encontrar o que procura ou execute uma ação incorreta.

O excesso de informações pode deixar a tela cansativa e dificultar a compreensão. Já as mensagens de erro pouco claras podem impedir que o usuário saiba o que aconteceu e como corrigir o problema.

Além disso, se o sistema não funcionar corretamente em celulares, parte dos usuários poderá ter dificuldades para acessar suas funcionalidades. Esses problemas podem gerar frustração, perda de tempo, redução da produtividade e até o abandono do sistema.

**Conclusão:** os testes de usabilidade são importantes para garantir que o sistema seja fácil de aprender, simples de utilizar, eficiente e agradável para os usuários.
